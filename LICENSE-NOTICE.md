# Aviso de licença

Este repositório contém apenas o roteiro de instalação.

O sistema instalado por ele é privado. Parte dele é obra de terceiros,
redistribuída sob a licença de origem — a lista completa, com autoria e termos
de cada uma, fica em `TERCEIROS.md` dentro do repositório principal.

A licença do repositório principal cobre apenas o que é autoria própria:
motores, contratos, regras, instalador e roadmap.
